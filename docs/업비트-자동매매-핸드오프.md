# 업비트 자동매매 봇 — 핸드오프 가이드

> 목적: **돈 버는 봇이 아니라, 공부/포트폴리오용 프로젝트.**
> 실제 돈은 "잃어도 되는 소액"만. 적금·투자(청년미래적금 등)는 절대 건드리지 말 것.
> 크롤러·데이터 파이프라인 실력 살리는 사이드 프로젝트로 딱 좋음 → 넥슨류 "AI/실전 문제해결" 채용에도 어필.

---

## ⚠️ 시작 전 마음가짐 (제일 중요)

- **"알아서 돈 버는 봇"은 없다.** 진짜 있으면 만든 사람이 조용히 부자 됐지 안 판다.
- 시장은 예측 불가 → 어떤 전략도 "항상 이기는" 건 없다. 봇은 **자동으로 잃기도** 한다.
- 그래서 목적은 **돈이 아니라 "배우고 만들어보는 것".** 잃으면 수업료, 잘되면 보너스, 실력·포폴은 무조건 남음.

---

## 전체 구조 (순서대로)

```
1) 데이터 가져오기      (API 키 필요 없음 — 공개 데이터)
2) 지표 계산            (이동평균선 등)
3) 매수/매도 신호 판단   (전략 = 규칙)
4) 백테스팅            ★절대 건너뛰지 말 것★
5) 소액 실전           (여기서만 API 키 필요)
```

---

## 1단계: 데이터 가져오기 (API 키 X, 돈 X, 지금 바로)

- 시세/차트 데이터는 **누구나 API 키 없이** 가져올 수 있음 (공개 데이터).
- 라이브러리: `pyupbit`

```python
# 설치 (터미널)
pip install pyupbit

# 첫 미션: 데이터 가져와서 보기
import pyupbit
df = pyupbit.get_ohlcv("KRW-BTC", interval="minute60", count=100)
print(df)
```

- 나오는 컬럼 = **OHLCV**: open(시가)/high(고가)/low(저가)/close(종가)/volume(거래량)
- 캔들(봉) 하나 = 이 5개 값. "차트"는 결국 이 숫자들의 나열.

### interval(봉 종류) 옵션
| 값 | 의미 |
|---|---|
| `minute1` ~ `minute240` | 1·3·5·10·15·30·60·240분봉 |
| `day` | 일봉 |
| `week` | 주봉 |
| `month` | 월봉 |

- `count` = 몇 개 가져올지 (최대 200)
- **초보는 일봉/1시간봉 추천.** 짧은 봉(1·5분)은 노이즈 많고 수수료 자주 나가서 어려움.
  - 짧은 봉 = 단타(스캘핑) → 어려움
  - 긴 봉 = 스윙(중장기) → 판단 쉽고 안전, 초보용

---

## 2단계: 지표 계산

가져온 숫자로 지표 계산 → 규칙 만들기. 초보용 지표:

- **이동평균선(MA) 교차** ← 초보 1순위. 로직 단순.
  - 예: 단기(5)선이 장기(20)선을 **위로 뚫으면 매수**(골든크로스), **아래로 뚫으면 매도**(데드크로스)
  - `df['close'].rolling(5).mean()` 이런 식으로 계산
- **RSI** — 과매수(70↑) 매도 / 과매도(30↓) 매수
- **볼린저밴드** — 상단 닿으면 매도 / 하단 닿으면 매수

→ **이동평균선 교차부터 시작.** 개념·코드 제일 쉬움.

---

## 3단계: 매수/매도 신호 판단 (전략)

- 지표로 규칙 만들기. 예) "골든크로스 발생 → 매수 신호"
- 전략은 교체 가능하게 함수/클래스로 분리해두면 나중에 여러 전략 실험 쉬움
  (※ 크롤러에서 쓴 Strategy 패턴 그대로 응용 가능)

---

## 4단계: 백테스팅 ★★★ (절대 스킵 금지)

- **"이 전략을 과거 데이터에 대입했으면 돈 벌었을까?"를 시뮬레이션**
- 실제 돈 넣기 전에 무조건 이거 먼저.
- 머릿속으론 좋아 보여도 과거 데이터 돌리면 "다 잃었네?" 하는 경우가 태반.
- 백테스팅 없이 실전 = 그냥 도박.
- 체크할 것: 총수익률, 승률, 최대낙폭(MDD), 거래 횟수(수수료 감안)

---

## 5단계: 소액 실전 (여기서만 API 키 필요)

- 실제 주문(매수/매도)은 **내 계좌를 건드리므로 API 키 필요**
- 업비트에서 API 키 발급 → 코드에 인증 → 소액 자동매매
- ⚠️ **API 키(특히 secret) 절대 코드에 하드코딩·깃 커밋 금지.** 환경변수(.env)로.
- ⚠️ **진짜 돈은 소액만.** 잃어도 되는 만큼. 적금/투자 자금 절대 X.

### 문서에 없던 걸 하나 추가했다: 과최적화 검증 (`04_optimize.py`)

백테스팅만으로는 부족하다. 파라미터를 이리저리 바꿔 제일 좋은 걸 고르는 순간
"과거를 외운 것"이 되어버린다. 그래서 훈련/검증 구간을 나누고 워크포워드로 재검증한다.

실제로 KRW-BTC 일봉 1000개로 돌린 결과:

```
훈련 구간 수익률 : +178.71%
검증 구간 수익률 :   +3.95%   ← 실제로 믿을 수 있는 숫자
워크포워드 4구간 : 평균 -2.59%, 흑자 1/4구간
→ 검증 구간 절반 이상에서 잃었다. 실전에 넣을 전략이 아니다.
```

**MA교차 5/20이 백테스트에서 +71% 나온 것도 이런 식이다.** 구간을 바꾸면 무너진다.
이 숫자를 보라고 만든 도구다. 실전 넣기 전에 반드시 이거 먼저 돌릴 것.
